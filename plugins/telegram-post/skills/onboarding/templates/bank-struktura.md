# Структура банка идей

Две таблицы. Хранить можно в файлах (`bank/temy.md`, `bank/ostatki.md`), в Notion (две базы) или в Google Таблице (две вкладки). Структура одинаковая.

## Темы
Список тем будущих постов.

| Поле | Значение |
|---|---|
| № | сквозной номер |
| Тема | короткое название |
| Блок | рубрика/направление (необязательно) |
| Вес | СЛ / Л / С / Т (или шкала автора) |
| Статус | Ждёт / В работе / Вышел |
| Пост | ссылка на вышедший пост |
| Описание | о чём тема, какую мысль несёт, кому адресована |

## Единицы (остатки)
Смысловые единицы из надиктовок и чатов, которые не вошли в текущий пост и ждут своей темы.

| Поле | Значение |
|---|---|
| Название | коротко, суть единицы |
| Тема | связь с темой из таблицы «Темы» (может быть пустой) |
| Блок | как у темы |
| Тип | Мысль / Сцена / Цитата / Образ / Наблюдение / Идея новой темы |
| Источник | Надиктовка / Чат / Идея на ходу / Мысль Claude |
| Откуда именно | например «надиктовка к #N, ДД.ММ.ГГГГ» |
| Статус | Ждёт / На решении / Сомнительное / В работе / Использовано / Отброшено |
| Где использовано | «#N» |
| ⚠ | Третьи лица / Клиент / Мат / Без подробностей / Распознавание [?] / Проверить |
| Комментарий | возможные адреса, пояснения к ⚠ |
| Дата | дата записи |
| Текст | дословные цитаты автора (с таймкодами, если есть) |

Важное: слова автора в «Тексте» хранятся дословно, не пересказом. Это главный материал для его голоса.

## В файлах
`bank/temy.md` — таблица тем (markdown). `bank/ostatki.md` — каждая единица отдельным блоком с заголовком `## Название` и полями строками «Поле: значение», ниже цитата.
