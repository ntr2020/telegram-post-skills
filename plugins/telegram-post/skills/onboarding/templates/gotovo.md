# Когда пост готов к показу

Перед тем как показать текст автору, Claude проходит этот список. В отчёте коротко пишет, что проверено и где сомневается. Автор правит список под себя.

## Мысль и рамка
- [ ] Главная мысль говорится одной фразой, и автор её одобрил.
- [ ] Каждый абзац работает на эту мысль. Абзац, который можно убрать без потери мысли, убран.
- [ ] Одна тема. Соседние темы названы и не затронуты.
- [ ] Не больше трёх значимых сцен, событий или людей (для лонгрида можно четыре).
- [ ] Длина в коридоре веса, ближе к нижней границе. Посчитана, а не оценена на глаз.

## Сокращение
- [ ] Отдельный проход сокращения сделан: слова, фразы и абзацы проверены тестом «выкинул — смысл не поменялся».
- [ ] Нет деталей, которые никуда не ведут.
- [ ] В отчёте есть список вырезанного, чтобы автор мог что-то вернуть.

## Голос
- [ ] Каждая фраза прослеживается до слов автора (надиктовка, его тексты). Связки Claude перечислены в отчёте.
- [ ] «Я», а не обобщённое «ты», если история личная.
- [ ] Нет признаков ИИ-текста (список в `golos.md`).
- [ ] Сверено с `golos.md`: приёмы, слова, эмодзи, запреты автора соблюдены.
- [ ] Глаголы проверены по `metodichka.md`, раздел «Глаголы»: действие в сценах совершенным видом, нет нейтральных и присоединительных глаголов и отглагольных существительных.
- [ ] Нет терминов, которых автор сам не оставил бы в посте.
- [ ] Нет слов из чужих текстов и стенограмм, даже удачных. Пишем словарём автора.
- [ ] Приёмы образцов не повторены механически.

## Логика и читабельность
- [ ] Первое предложение сразу по делу, без разгона.
- [ ] Структуру можно пересказать одной фразой по частям без «кстати» и «а ещё».
- [ ] Каждое следующее предложение вытекает из предыдущего. Нет очевидных тезисов после сцены, которая их уже показала.
- [ ] Пост развивается, а не перечисляет. У него есть финал, он не обрывается на последнем факте.
- [ ] **Дыры не заклеены.** Там, где между тактами не было связки, стоит слово автора или его честное «не знаю», а не фраза Claude.
- [ ] Абзацы не длиннее 5–6 строк, длина фраз чередуется.
- [ ] **Прочитан подряд глазами читателя, который не был в нашем чате.** Ни одно утверждение не опирается на разбор, надиктовку или обсуждение вне текста. Мест, где возникает «а как?» и в тексте нет ответа, не осталось.

## Этика
- [ ] Всё, что было «без подробностей» или под сомнением, подтверждено автором или убрано.
- [ ] Третьи лица и клиенты: использование одобрено, узнаваемых деталей нет. (Дополни правилами автора из `CLAUDE.md`.)

## Оформление
- [ ] Жирным выделены одна-две ключевые фразы, а не россыпь слов. В отчёте сказано, что выделено и почему.
- [ ] Курсив, спойлер, зачёркнутое и разделитель стоят по месту, а не для красоты.
- [ ] Пост показан блоком с кодами разметки Telegram, готовым к копированию (`**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `моноширинный` ``, `||спойлер||`, `[текст](ссылка)`). Не все клиенты Telegram разбирают коды при вставке, поэтому проверь на своём. Ссылки при копировании из чата могут не сохраняться: тогда расставь вручную.
- [ ] Хештеги/рубрики: если у автора есть схема в `CLAUDE.md`, предложена строка тегов отдельно от поста, только из утверждённого списка.

## Хвосты
- [ ] Неиспользованное внесено в банк идей (после того как автор подтвердил раскладку).
- [ ] Отчёт в 2–5 строк: где связки, что вырезано, что проверить. Без самооправданий.

## Подсчёт знаков
Знаки с пробелами, у markdown-ссылки считается только видимый текст. PowerShell:

```powershell
$t = Get-Content -Raw -Encoding UTF8 "posts\NN-slug\final.md"
($t -replace '\[([^\]]+)\]\([^)]+\)', '$1').Trim().Length
```

Python (если нет PowerShell):

```python
import re,sys
t=open(sys.argv[1],encoding='utf-8').read()
print(len(re.sub(r'\[([^\]]+)\]\([^)]+\)',r'\1',t).strip()))
```
