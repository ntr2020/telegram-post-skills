# telegram-post-skills

Плагин для Claude Code: алгоритм производства текстов для Telegram-канала.

Внутри три скилла:
- `onboarding` знакомится с автором: что за канал, для кого, каким голосом пишет, где хранит идеи. Всё записывает в файлы рабочей папки автора.
- `razbor` разбирает надиктовку или поток мыслей на смысловые единицы и раскладывает их по банку идей: что в текущий пост, что в запас под будущие темы.
- `post` ведёт от темы до готового поста: главная мысль → структура → материал для автора → текст → сокращение → самопроверка.

В плагине нет знаний о конкретном авторе. Всё личное (голос, читатель, правила, банк) скилл `onboarding` собирает вопросами и кладёт в рабочую папку.

## Установка

В Claude Code выполни по очереди:

```
/plugin marketplace add ntr2020/telegram-post-skills
/plugin install telegram-post@telegram-post-skills
```

Затем открой Claude Code в папке, где будет жить канал (создай пустую, например `Мой-канал`), и напиши:

```
Запусти онбординг: скилл telegram-post:onboarding
```

## Что понадобится

- Методичка по копирайтингу в PDF (если передали): путь к файлу скажешь на онбординге.
- 3–10 твоих опубликованных постов, которыми ты гордишься (текстом): по ним скилл поймает голос.
- Решение, где хранить банк идей: файлы в папке, Notion или Google Таблица.

## Структура

```
.claude-plugin/marketplace.json
plugins/telegram-post/

  skills/razbor/       SKILL.md
  skills/post/         SKILL.md
```
